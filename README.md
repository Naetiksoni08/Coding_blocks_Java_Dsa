# ☕ Java Data Structures & Algorithms Repository

This repository documents my structured journey of mastering Data Structures and Algorithms (DSA) in Java, covering concepts from basic fundamentals to advanced competitive programming. 

It contains foundational logic built within Eclipse, complete coursework assignments (Coding Blocks), and optimal solutions for **Daily leetCode problems**.

---

## 🛠️ Covered Topics & Data Structures

* **Core Java & OOP** — Classes, Objects, Inheritance, Polymorphism, Abstraction, Encapsulation
* **Basic Programming Logic** — Pattern Printing, Bit Manipulation, Low-Level Mathematics
* **Linear Data Structures** — Arrays, Matrices, Strings (StringBuilder), Linked Lists, Stacks, Queues
* **Non-Linear Data Structures** — Trees, Binary Search Trees (BST), Heaps (Priority Queues), HashMaps, Graphs
* **Algorithmic Paradigms** — Two-Pointer Patterns, Sliding Windows, Prefix Sum, Recursion, Backtracking
* **Advanced Optimization** — Dynamic Programming (Memoization & Tabulation), Divide and Conquer
